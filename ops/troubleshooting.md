# Chapter 9: Troubleshooting & Exit Ramps

## 🎯 1. Purpose
To identify and mitigate acute system failures, recursive loops, and physiological crashes. This module provides the "Hardware Interrupts" needed to regain control when the Narrator (Brett) has been high-jacked by Fred’s survival signals.

## 🔒 2. Canonical Definitions (Symbol Lock)
* **Logic Bomb:** A recursive thought loop where Brett tries to solve a problem using the same logic that created the problem (01 State).
* **The Freeze:** A state of high HRV but zero mobility. This is a "Dorsal Vagal Shutdown" (10 State). 
* **Anxiety Spike:** A non-linear jump in Heart Rate (HR) without a corresponding increase in physical activity.
* **Exit Ramp:** A pre-defined physical action that overrides all cognitive processing.

## 🛠️ 3. Operational Procedure (The "How")

### Failure Mode 1: The Recursive Loop (Overfitting / 01)
* **Identification:** Brett is arguing with himself; jaw is tight; breathing is shallow.
* **The Ramp:** **The "Stop-Drop-Shake" Protocol.** 1. Stop all typing/coding immediately. 
    2. Drop your gaze to the floor (break the screen-lock). 
    3. Execute Chapter 1: The Shake for 20 seconds.

### Failure Mode 2: The Freeze (Shutdown / 10)
* **Identification:** High HRV (appearing "calm" on paper) but unable to initiate action; feeling "heavy" or "numb."
* **The Ramp:** **The "Sensory Ping."** 1. Force a change in temperature (Splash cold water on the face). 
    2. Identify 3 physical objects in the room. 
    3. Execute a single, vigorous "Push" against a wall to re-engage the hardware.

### Failure Mode 3: The Anxiety Spike (Engine Overheat)
* **Identification:** HR > 100 BPM while sedentary. 
* **The Ramp:** **The "Vagal Brake" Hold.** 1. Place both hands over the solar plexus (Bruce). 
    2. Long exhale (8 counts). 
    3. Do not return to the task until HR drops below 85 BPM.



## 📊 4. Telemetry Return Codes (The Data)
* **Success (Recovered):** * HR returns to within 10% of baseline.
    * RMSSD stabilizes.
    * Narrative: Brett moves from "What if?" to "What is."
* **Critical Error (Persistent Loop):** * Telemetry remains in the 01/10 regime after 3 ramp attempts.
    * Action: **Hard Power Down.** Sleep or 20-minute horizontal render (Chapter 1, Protocol B).
